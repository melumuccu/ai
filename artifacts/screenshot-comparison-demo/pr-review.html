概要

本 PR はフロントエンド UI の配色変更デモです。見出し色（青 → 紫）と CTA ボタン色（オレンジ → 緑）を before.html / after.html で比較し、同一ビューポートのスクリーンショットを img-comparison-slider で提示します。

スクリーンショット比較

左（first）が修正前、右（second）が修正後です。中央ハンドルをドラッグして差分を確認してください。

撮影条件

  • ビューポート: 1280 × 800 px（deviceScaleFactor: 1）
  • 修正前 URL: before.html（ローカル file://）
  • 修正後 URL: after.html（ローカル file://）
  • branch: cursor/screenshot-comparison-demo-96b6

変更差分

要素 修正前（before） 修正後（after）
見出し色 #1e40af（青） #6b21a8（紫）
CTA ボタン色 #ea580c（オレンジ） #16a34a（緑）

確認結果

  • 1280×800 ビューポートで before / after を撮影し、data URL として本 HTML に埋め込み済み
  • img-comparison-slider@8 CDN でスライダー表示を確認
  • テンプレート由来のコメントコア（選択→追加→編集→削除→全件コピー）と daisyUI 構成を維持

残リスク

  • 本デモはローカル file:// 上の静的 HTML のみ。本番デプロイや認証付き画面は対象外
  • data URL 埋め込みのため HTML ファイルサイズが大きい（約 55 KB 超の画像データを含む）
  • ブラウザや OS によってスライダーの描画・操作感がわずかに異なる可能性がある
