# 概要

## Goal

artifact を、単体で一貫した最終成果物として読めるよう改訂する。

次の不要な痕跡を artifact に残さない。

- ユーザーの prompt
- 会話履歴
- 中間推論
- 実装制約
- ツール選択
- 回避した代替案
- prompt エンジニアリング指示
- 制作時の足場
- 意図伝達のためだけに与えられた例
- 会話中の修正フィードバック

最終 artifact は、制作会話から組み立てたものではなく、本来の読者向けに意図的に設計したものとして読めること。

## Core Principle

会話は制作コンテキストであり、artifact 本文へ自動的に載せる内容ではない。

artifact に残す前に、各記述を次のいずれかに分類する。

1. artifact の読者が本当に必要とするユーザー向け内容
1. artifact に影響させるが本文へは載せない制作ガイダンス
1. 除去すべき会話の残留物

カテゴリ 1 だけを artifact に直接載せる。

カテゴリ 2 は構成、トーン、スコープ、前提、デフォルト、例、命名、設計選択へ間接的に反映する。

カテゴリ 3 は除去する。

## 対象 artifacts

作業セッションで生成または改訂するユーザー向け artifacts に本 skill を適用する。例:

- 単一 HTML ドキュメント（issue / PR レビュー、説明、プランニング、walkthrough）
- 注釈付きガイド
- 共有用静的説明ページ

作業セッションで生成した単一 HTML は artifacts の一つである。生成、改訂、公開の前に本 skill を適用する。

## source 帰属

kotek-7/dotfiles の `sanitize-artifacts` を kf-global 向けに適応した。
