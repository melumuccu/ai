# リポジトリとホームの差分

## 基本方針

リポジトリ（`.agents/skills/`）とホームディレクトリ（`~/.agent/skills/`）の skill 内容が一致しないことは正常である。
差分をバグや設定ミスと断定しない。

## 差分が生じる典型理由

1. **マージ前の作業中変更**: リポジトリ側にのみ存在する未マージ変更
1. **同期タイミング差**: main マージ後、ユーザーが vercel-labs/skills で同期するまでの時間差
1. **配置経路の違い**: リポジトリは worktree / branch 単位、ホームは vercel-labs/skills 同期結果
1. **バージョン差**: ホーム側が古い main スナップショットのまま

## 必須手順

1. リポジトリとホーム skill を比較する → 差分の有無を事実として報告する
1. 差分がある → 上記典型理由のいずれかに該当するか確認する
1. skill 修正依頼がある → リポジトリ側を編集し、ホーム側は触らない
1. ユーザーが最新化を求める → main マージと vercel-labs/skills 同期を案内する

## 禁止事項

- 差分を異常・不具合と断定してホーム skill を直接修正しない
- リポジトリ未マージ内容をホームへ手動コピーして差分解消しない
- ホーム skill をリポジトリの正として逆反映しない

## 完了判定

1. 差分を正常な状態として説明している
1. 修正対象はリポジトリ側に限定している
