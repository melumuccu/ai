# 出力形式

## 必須見出し順

次の見出しをこの順で必ず含める。

1. **結論**（進める / 条件付き / 差し戻し）
1. **Blocking issues**
1. **Non-blocking risks**
1. **Open questions**
1. **受け入れ条件**（条件付きのときのみ）

## 各セクションの書き方

- 各項目は具体的根拠を付ける（引用・仮定の明示）
- 空セクションは「なし」と書く
- 条件付き承認のときだけ「受け入れ条件」見出しを置く。進める・差し戻しのみのときは省略する

## 出力例（骨格）

```markdown
## 結論

条件付き — ○○の前提が検証されるまで本番投入は差し控える。

## Blocking issues

- ...

## Non-blocking risks

- ...

## Open questions

- ...

## 受け入れ条件

- ...
```

進める・差し戻しのみで条件付きでない場合、最後の「受け入れ条件」見出しは出さない。
