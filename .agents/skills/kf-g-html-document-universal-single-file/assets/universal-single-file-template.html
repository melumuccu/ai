用語解説

本文を選択すると、右側（狭い画面では下）にコメントカードが追加されます。再読み込み後も同じ URL 上で復元されます。 左側（狭い画面では本文上）には、viewport 内に見えている専門用語の解説カードが文書順に積み上がります（例: ICP、TAM）。スクロールで見えなくなった用語のカードは非表示になります。

単一 HTML レビュー資料の書き方

このテンプレートは、ビルド不要の単一 HTML でレビュー資料を作成するための起点です。本文を選択してコメントを付け、左レールで専門用語を補足できます。

本文サイズの選び方

通常の説明文は text-base を使います。読者が流し読みしやすいよう、1段落1論点を心がけてください。

補足や注釈は text-sm で書きます。表や steps に載せた内容を段落で繰り返さないでください。

強調が必要なとき

結論や判断の要点は text-lg で1文にまとめます。見出し h3 と同じサイズですが、色と余白で区別します。

概要

ドキュメントの目的

  • ビルド不要の単一 HTML で説明ページを作る。
  • daisyUI v5 + Tailwind browser CDN でスタイルする。
  • コメントコアは vanilla JS のみで動作する。
  • 左レールに ICP など、viewport 内の専門用語解説を文書順に積み上げ表示する。

重要な結論や強調したい1文は text-lg で書く。

要約の次は、比較なら table、手順なら steps や Mermaid で構造化する。表・図に載せた事実は段落で繰り返さない。

使い方

  1. 説明したい箇所をドラッグして選択する
  2. 表示される入力欄にコメントを書いて追加する
  3. ハイライトまたはカードから個別コピー・編集・削除ができる

表・steps で拾い切れない補足は、1段落1論点の短い段落にまとめる。

比較表ソートの説明と実装例

比較表は、初期表示で最も重要な列を降順に並べ、見出しのボタンで比較軸を切り替えます。 表示単位（% や点）はラベルに置き、ソート用の生データは data-sort-value に分離します。

良い例

fit 列に 100、75 のような数値を持たせ、表示は「100%」「75%」にする。

「S」「A」や「十分」「要確認」は、順位を表す数値を data-sort-value に明示する。

悪い例

「100%」をそのまま文字列比較したり、「S」「A」を自然言語の順序だけに任せたりする。

表示文言・単位の変更で並び順が変わるため、比較軸の意味が壊れる。

初期状態は fit 降順。見出しを押すと同じ列の昇順・降順を切り替えます。
gBizINFO 100% S 2026-08-10 確認済み
Bizloop 75% A 2026-08-08 要確認
その他 A 50% B 2026-08-01 未確認
その他 B 50% B 2026-07-29 未確認
その他 C 未算出 C 2026-07-20 未確認
2つ目の表は priority 昇順。複数表をスクロールして固定 clone の対象切替を確認できます。
公開台帳 1 確認済み
事業者名鑑 2 レビュー中
その他資料 3 未確認

検証データと確認項目

  • 初期順が gBizINFO（100%）→ Bizloop（75%）→ その他（50%）になり、同値のその他 A/B は元順を保つ。評価は S/A/B/C を 3/2/1/0 の意味順位で持つ。
  • 数値・文字列・日付をそれぞれソートし、未定義値や NaN は末尾へ寄せる。
  • 「未算出」は number 列の非数値データとして末尾に移動し、表示単位をソート値へ混ぜない。
  • 2つの表をスクロールし、見出しボタン、横スクロール、navbar 下の固定 clone の対象切替を確認する。clone のセル押下は元ボタンを操作する。
  • 表のソート操作でテキスト選択コメントが開かず、ソート後も既存コメントのレイアウトが再計算される。
