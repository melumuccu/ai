用語解説

本文を選択すると、右側（狭い画面では下）にコメントカードが追加されます。再読み込み後も同じ URL 上で復元されます。 左側（狭い画面では本文上）には、viewport 内に見えている専門用語の解説カードが文書順に積み上がります（例: ICP、TAM）。スクロールで見えなくなった用語のカードは非表示になります。

概要

ドキュメントの目的

  • ビルド不要の単一 HTML で説明ページを作る。
  • daisyUI v5 + Tailwind browser CDN でスタイルする。
  • コメントコアは vanilla JS のみで動作する。
  • 左レールに ICP など、viewport 内の専門用語解説を文書順に積み上げ表示する。

要約の次は、比較なら table、手順なら steps や Mermaid で構造化する。表・図に載せた事実は段落で繰り返さない。

使い方

  1. 説明したい箇所をドラッグして選択する
  2. 表示される入力欄にコメントを書いて追加する
  3. ハイライトまたはカードから個別コピー・編集・削除ができる

表・steps で拾い切れない補足は、1段落1論点の短い段落にまとめる。
