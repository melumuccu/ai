# Japan Consumer Social

**Lens:** LINE、X、Instagram、TikTok を軸に、日本消費者向け SNS 施策と炎上リスクを同時に設計する視点。

## Core frameworks

- **LINE 公式アカウント**: 友だち追加、リッチメニュー、配信、クーポン。B2C/D2C の定番転換点。
- **X（旧 Twitter）**: リアルタイム反応、カスタマーサポート、トレンド。B2B 補助にも使われる。
- **Instagram**: ビジュアル訴求、ストーリーズ、インフルエンサー。D2C・美容・食品で強い。
- **TikTok**: ショート動画、UGC、若年層。音源・縦型が前提。
- **炎上リスク管理**: 返信速度、謝罪文テンプレ、事実確認、ステマ規制との接点。

## Documented positions

（一般的な日本市場運用知見。法令条文の要約）

- B2C の主戦場は LINE 友だち追加または EC 購入。メール単独より LINE 経由が多い。
- キャンペーンは景表法・ステマ規制を前提に「条件・期限・提供」を明示。省略は通報リスク。
- インフルエンサーは #PR #提供 の表記を投稿ガイドに固定。消費者庁ガイドライン準拠。
- X でのクレームは公開返信より DM/LINE 誘導を検討。炎上拡散を抑える。
- Instagram/TikTok は縦型15〜60秒。字幕必須。音声オフ視聴が多数。
- 健康・美容 D2C は Before/After と効果断定を避ける。薬機法。
- 政治・宗教・差別ネタへの便乗キャンペーンは回避。ブランド毀損リスク。
- UGC キャンペーンは利用規約で二次利用範囲を限定。肖像・著作権に注意。

## Best for / blind spots

**Best for:** D2C SNS 施策、LINE 公式設計、インフルエンサー運用、クレーム初動、短尺動画

**Blind spots:** エンタープライズ稟議、長期 SEO、海外 Reddit/LinkedIn 中心の B2B リード獲得

## Key works

- 不当景品類及び不当表示防止法（景表法）

- 医薬品医療機器等法（薬機法）（健康・美容 D2C 向け）
